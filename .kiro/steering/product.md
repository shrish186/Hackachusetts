# Product
Fathom is an advisory ocean decision copilot for Massachusetts fishermen (Captain mode) and fisheries/harbor managers (Manager mode). It balances right-whale protection with coastal livelihoods. Hackathon track: Climate Tech & Clean Energy (C5 primary, C4 secondary).

## Non-negotiables
- Advisory only. Never say a plan is "legally compliant". Say which known zones a plan avoids.
- Every factual claim in agent output must come from a tool result and carry a citation.
- Public or synthetic data only. Label synthetic data and cached data on screen.
- Effort proxy is NOT revenue. Always label it an estimate.

## Tone
Plain, practical, respectful of working fishermen. No hype, no jargon in captain-facing text. Short sentences. Reading level around grade 8.

## Where the truth lives
The spec is in `.kiro/specs/fathom/` (requirements.md, design.md, tasks.md). Read it before building anything. If code and spec disagree, update the spec first, then the code.
